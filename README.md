Implementation of deep Reinforcement Learning algorithms on [Gymnasium](https://gymnasium.farama.org/) environments using [TorchRL](https://docs.pytorch.org/rl/stable/index.html).

Algorithms:
- Deep Q-Network (DQN)
- Deep Deterministic Policy Gradient (DDPG)
- Proximal Policy Optimization (PPO)

 
Algorithms implemented without TorchRL (`no_lib` folder):
- Vanilla Policy Gradient (VPG) (a.k.a. REINFORCE)
- Proximal Policy Optimization (PPO)
